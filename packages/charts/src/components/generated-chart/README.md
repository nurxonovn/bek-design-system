# Generated chart

Figma: **4.18 Chart · Generated chart** — AI yordamchi foydalanuvchi ma'lumotidan yasagan chart kartasi: AI belgisi va vaqt, sarlavha, manba, chart sloti, AI insight va amallar (Table · Code · Save). Holat (`state`): `default` · `generating` · `error`.

```tsx
<GeneratedChart
  title="Revenue by month, 2026"
  timestamp="Just now"
  source="Source: payments.csv · 1 240 rows"
  insight="Revenue grew 34% since January; May dipped after the price change"
  onShowTable={openTable}
  onShowCode={openCode}
  onSave={save}
>
  <ChartContainer>{(width) => <LineChart width={width} area labels={months} series={series} label="Revenue grew 34%" />}</ChartContainer>
</GeneratedChart>

<GeneratedChart state="generating" title="Revenue by month, 2026" step="Step 2 of 3" progressNote="Reading 1 240 rows from payments.csv and choosing a chart type" />
```

- **Qachon:** chart bor chat javoblari ("show revenue by month"), Ask-the-chart va hisobot quruvchilar. `generating` — model hali qurayotganda.
- **Tarkib:** sarlavha qatori — sparkles + "Generated by BEK AI" (Label/S · `text/secondary`) va vaqt (Caption/M · `text/tertiary`); sarlavha Title/M; manba Caption/M; chart sloti — istalgan Chart/\*; AI insight (`dataviz/ai/soft` · `text/utility`); amallar — 3.1 Button Flat-secondary.
- **Qoida:** manba va qatorlar sonini doim ko'rsating — foydalanuvchi tekshira olsin. Amallar: Table (raqamlarni ko'rish), Code (so'rov), Save.
- **Generating:** chart shaklidagi 5.7 Skeleton, Spinner, "Step 2 of 3" va model nima qilayotgani (`role="status"`); karta `aria-busy`.
- **Error:** Chart/Card Error holati shu karta ichida — 5.3 Empty state `role="alert"` + "Try again" (`onRetry`).
- **O'lchamlar:** eni konteynerga ergashadi; padding `scale/20`, bo'limlar orasi `scale/16`, radius `radius/surface/md`; skeleton plot `chart/height/md`.
